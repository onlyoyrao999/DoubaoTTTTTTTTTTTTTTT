# 豆包 (Doubao) 视频智能分析与爆款生产 Skill

> **为豆包（字节跳动）、扣子 (Coze)、飞书智能体定制的自媒体全自动化视频解构与爆款资产创作引擎**。  
> **核心优势：零外部 API Key 依赖！** 豆包本身自带强大的多模态视频理解能力以及【每日免费文生图额度】。全程按照本 Skill 指令自主决策，全自动完成故事摘要、时间轴拆解、3:4 写实夸张封面（强制中文短标题）、4 条热门爆款长标题、以及极具讨论热度的第三人称川味大白话反思评论。

---

## ⚡ 核心亮点：为什么不需要任何 API Key？

1. **豆包原生多模态视频理解**：用户直接上传或在对话框中发送视频，豆包内置的视觉插件会自动进行关键帧抽取与时序理解，无需调用外部视觉接口。
2. **豆包自带免费文生图额度**：豆包拥有内置生图插件，每日享有免费生图额度。本 Skill 指令已对齐豆包生图规范，自动调用其内置生图能力输出 **3:4 比例极具冲击力的写实夸张人物封面**，并在图版黄金位置强制印上全中文短标题。
3. **全程自主决策闭环**：完全遵循“不要咨询我，按你自己的想法”，无需反复人工确认，一键交付自媒体整套爆款物料。

## 📖 核心功能概览

### 1. 自动化视频深度解构与关键时间轴
- **多模态关键帧抽样**：用户拖拽上传任意本地视频（MP4/WebM/MOV），浏览器端自动提取关键帧与时序数据，毫秒级分析。
- **详细内容摘要（Summary）**：穿透表象，深度剖析冲突焦点、人物心理起伏及反转内核。
- **关键事件时间轴（Timeline）**：精准按 `[mm:ss]` 时间戳提取节点，包含具象动作细节与戏剧张力分值（1-100），支持点击时间轴与播放器画面同步联动。

### 2. 3:4 视觉冲击力《写实夸张封面》（强制嵌入全中文短标题）
- **强制印上全中文短标题**：在 3:4 竖版画面黄金视觉位嵌入 4~8 个字的超强冲击力中文短标题（如“当场破防！”、“一杠救命！”、“饭碗砸了？”），并带有立体描边与警示底衬，吸睛度拉满。
- **电影级夸张写实神态**：基于真实人物电影质感，极度放大人物生理情绪张力（瞳孔骤缩、冷汗直流、咬牙切齿、青筋暴起）。
- **900×1200 超清 Canvas 画板**：内置 4 种爆款主题配色（警示亮黄/猩红风暴/极夜黑金/赛博深蓝），支持**一键下载超清 PNG**及**复制中英文生图 Prompt**。

### 3. 4 条高点击率热门爆款长标题
- 围绕“极致反转悬念”、“情绪共鸣爆点”、“反常识对比”、“深度社会反思”等自媒体算法偏好设计，提供传播力评分与一键复制功能。

### 4. 第三人称川味大白话反思评论与专属标题
- **语言风格**：多用短句，通篇大白话，自然穿插地道四川方言口头禅（如：“说老实话”、“硬是”、“算求了”、“格老子”、“哪门讲喃”）。
- **具象动作细节**：拒绝抽象空洞的抒情，全是具体的肢体细节动作（掐灭烟头、摔了筷子、擦冷汗、跺脚、把手机反扣在桌上）。
- **终极反问抛梗**：末尾以直击痛点的反问句收尾，引发评论区网友激烈争辩。
- **评论专属长标题**：严格限制在 **25 个汉字字符以内**，实时字符计数核验。
- **严苛合规质检（绝对红线）**：
  - ❌ 绝不出现“铁蛋”
  - ❌ 绝不出现“视频”、“视频中”、“看完视频”这几类字样
  - ❌ 绝不评价机器人穿的服装
  - ❌ 严禁使用排比句，严禁“不仅仅、更是、赋予、维度”等假大空虚词

### 5. 豆包 Skill 技能标准定义与一键导出
- 内置开箱即用的系统提示词（System Prompt）、JSON Schema 规范协议及部署指南，可直接复制粘贴导入到豆包智能体或扣子 (Coze) 工作流中。

## 🛠️ 技术架构

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons + HTML5 Offscreen Canvas
- **后端**：Node.js + Express + `@google/genai` (搭载 Gemini 3.8 Flash 多模态视频推理引擎)
- **多模态链路**：客户端视频时序抽样 -> Base64 关键帧注入 -> 服务端 Schema 结构化提取 -> 实时红线规则清洗 -> 动态 3:4 封面合成渲染

## 🚀 快速上手与本地启动

### 1. 准备环境变量
在项目根目录创建或检查 `.env` 文件：
```env
GEMINI_API_KEY="你的_GEMINI_API_KEY"
PORT=3000
```

### 2. 安装依赖并启动开发服务
```bash
# 启动全栈服务（支持热加载与 Vite 前端集成）
npm run dev
```

浏览器访问 `http://localhost:3000` 即可开始使用。

### 3. 生产打包构建
```bash
npm run build
npm start
```

## 🤖 豆包 / 扣子 (Coze) 智能体部署指南

若需将本工作流作为独立技能部署在豆包应用或扣子平台：

1. **新建技能/智能体**：在豆包智能体管理后台或 Coze (coze.cn) 中点击创建。
2. **复制提示词**：进入应用顶部的【豆包 Skill 规则定义】选项卡，一键复制预设的标准系统提示词。
3. **启用多模态能力**：在技能插件中开启“视频理解”或“多模态视觉理解”支持。
4. **即时调用**：在对话框中发送任意视频文件，豆包将自主输出完整摘要、时间轴、封面设计、爆款标题与川味评论。
