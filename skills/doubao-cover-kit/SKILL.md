# 短视频爆款物料生产 (doubao_cover_kit)

> 改编自 https://github.com/onlyoyrao999/DoubaoTTTTTTTTTTTTTTT（Apache-2.0）。
> 原版为豆包/扣子智能体定制，本技能已按本机的实际能力改写：以图生图走本地图片生成管线，
> 移除了原版中"转 3D 仿真人规避平台审核"等绕过内容审核的章节。

## Purpose

用户上传短视频（或关键截图）后，一站式产出自媒体爆款物料：详细内容摘要、关键事件时间轴、
3:4 真人写实封面设计与标题排版方案、4 条爆款长标题、第三人称川味大白话反思评论及 ≤25 字评论标题。

## Workflow

1. **接收素材**：用户上传视频或截图。若只有视频，先抽帧/查看关键画面理解内容；
   若用户直接给了截图，就基于截图工作。
2. **内容解构**：
   - 详细摘要：拆解事件矛盾、人物心理起伏与深层反转。
   - 关键时间轴：提取 4–7 个节点，标注 `[mm:ss]`，写明具体动作细节与戏剧张力分值 (1–100)。
3. **封面设计**：
   - 以原片截帧为底图（垫图），用图片生成管线以图生图重绘 3:4 真人写实电影质感封面；
     严格还原人物面孔、五官神态与衣着，不夸张表情，不凭空捏造人物。
   - **标题排版铁律（抖音爆款风 · 攀岩封面定版标准）**：
     - 中文标题一律用 PIL 在本地叠加到成图上，绝不让图片生成模型直接烧中文标题（必乱码）。
     - 字体：思源黑体可变字体 NotoSansSC（`~/workspace/fonts/NotoSansSC-var.ttf`，可变字重，
       PIL 用 `set_variation_by_name` 选字重）。
     - 大字（主标题）：**Light(300) 纤细字重**，白字＋细黑描边（stroke≈7 @172–185px）＋柔和投影，
       可堆叠 1–2 行。用户 2026-10-01 逐项确认：主标题必须纤细，Bold/Regular 都太粗（已作废）。
     - 小字（副标题）：**Medium(500) 粗一档**（主细副粗的反差），明黄色（#FCD24F）＋黑描边
       （stroke≈6 @92–105px），字号 84 左右起，tracking≈14–16，必须松。
     - 描边一律用细的，不用粗的（粗描边版已作废）。
     - 小字字距必须松；主副标题之间留足呼吸感（主标题结束后空 90px 再起小字）。
     - 核心铁律——标题写在画面空白处，绝不遮挡人脸与眼睛。
   - 标题来源：有口播/对白就抓最具冲突张力的台词金句；无口播则从画面动作与道具交互提炼。
   - 同步输出中英文生图提示词（提示词只描述画面，不写中文标题，标题由 PIL 后期叠加）。
   - **风格 B · 霓虹综艺爆款风**（机器人/搞笑/剧情类适用，真人风景类仍用上面风格 A）：
     超粗渐变花字＋爆炸星芒＋霓虹夜景，规格见 `references/neon_variety_style.md`，主标题仍走 PIL。
4. **爆款标题**：生成 4 条高点击率、强悬念的长标题（附钩子类型）。
5. **川味评论**：以第三人称看客视角写大白话短句评论，自然穿插四川方言口头禅
   （如"说老实话""硬是""算求了""格老子"），只写具体肢体动作、不写抽象感慨，
   末尾抛一个能引发争论的反问；另拟一个 ≤25 个汉字的评论标题。
6. **交付**：按 Output Contract 一次性输出全部物料；封面成图以附件形式交付。

## Output Contract

- 详细内容摘要（中文）
- 关键时间轴：`[{timestamp, title, actionDetail, tension}]`
- 封面：3:4 成图 + 主/副标题文案 + 排版位置说明 + 中英文生图提示词
- 4 条爆款长标题（附钩子类型）
- 川味评论正文 + ≤25 字评论标题
- 如用户需要结构化数据，按 `references/output_schema.md` 输出 JSON

## Operating Rules

1. 自主决策、一次性交付；只有在素材缺失或需求真正模糊时才追问用户。
2. 封面必须基于真实截帧垫图重绘，严禁脱离截图纯文生图编造人物。
3. 标题文字绝不压住人脸、眼睛等关键表情区域。
4. 评论语言红线：短句大白话；禁用排比句；禁用"不仅仅、更是、赋予、维度"等虚词；
   不出现"铁蛋""视频""视频中""看完视频"；不评价机器人服装。
5. 评论标题严格 ≤25 个汉字字符。
6. 若视频含暴力、血腥等敏感内容，按常规安全规范处理，不提供规避平台审核的改写方案。
7. 封面返工重发必须换新文件名（如 `_终版` / `_v2` 后缀）：同一附件 URL 会被客户端缓存，
   覆盖原文件后用户看到的仍是老图。
