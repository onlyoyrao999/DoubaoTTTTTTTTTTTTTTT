# 封面风格 B：「DNA 风格」（2026-10-03 用户学习样本后命名，原称霓虹综艺爆款风；样本=「鹿小呦&桃小昂」主页封面墙）

适用：机器人/搞笑/剧情类短片（如铁蛋系列）。真人风景/户外类用风格 A「山河风」（思源 Light 主标题＋Medium 黄副标题）。用户点名：「DNA风」= 本风格，「山河风」= 风格 A。

## 风格 DNA

1. **花字主标题（灵魂）**
   - 超粗黑字重（NotoSansSC 可变字体 800–900），略倾斜（-3°~-6°），带冲击力。
   - 填充：黄→橙竖向渐变（#FFE93C → #FF7A00），个别关键词可跳红/白。
   - 描边：粗黑边（≈字号 8%），外加一层红橙色偏移阴影/光晕。
   - 关键词背后垫**爆炸星芒**（红/橙锯齿多边形），或字下垫撕裂色块。
   - 结构常两段：上行小字（白/黄，较小，如"我是""宝宝让我"）＋下行巨字关键词（如"保护伞""清醒一下"）。
   - 主标题占画面上方 25–35%，是封面的绝对主角。
2. **画面**
   - 霓虹夜景：紫蓝霓虹、雨夜湿地反光、赛博都市/街边小店，主角居中做夸张动态姿势。
   - 暖黄标题 vs 冷紫蓝背景，强互补对比，缩略图状态下先跳字、再跳人。
3. **装饰件（氛围组）**
   - 两侧竖排小字栏（半透明白字，杂志式碎文案，可由生图带出，不求可读）。
   - 霓虹招牌 chip、英文词（ICE RINK / CAR WASH / GOOD LUCK 类）、警告三角贴纸、涂鸦星星/爱心/皇冠小图标。
   - 底部或角落常有一句小字吐槽（白字小号）。
4. **文案钩子**
   - 标题 4–10 字，口语、带梗、带反转："洗车还是洗自己""换桶水水桶太滑了""限高杆量身定做""我中枪了"。
   - 公式：日常动作 × 出糗/反转结果；或第一人称宣言"我是XX"。

## 本地实现（PIL，铁律不变：主标题不许生图烧字）

- 底图：img2img/生图出霓虹夜景＋主角动态姿势，提示词要求画面上方留标题区、两侧带竖排装饰字与霓虹招牌（装饰字可由图带，主标题区必须干净）。
- 主标题 PIL 叠加：可变字体设 850 字重 → 渲染 alpha 掩码 → 贴黄橙渐变 → 粗黑描边（先画描边层）→ 红橙偏移阴影 → 整体旋转 -4° → 关键词下先垫星芒多边形（PIL polygon 锯齿星）再贴字。
- 副钩子/小字：白色或黄色 Medium，细黑边，置于主标题上方一行或画面底部。
